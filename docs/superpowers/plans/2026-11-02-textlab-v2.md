# TextLab v2 Implementation Plan

> Use superpowers:executing-plans to implement task-by-task.

**Goal:** Deliver a tested TextLab source repository and a deployable frontend, with truthful deployment and model-readiness status.
**Architecture:** Browser-only style analysis, React UI, protected FastAPI rewriting endpoint, configurable server-side model adapters.
**Tech Stack:** React, Vite, Node test runner, Python/FastAPI/httpx, pytest, Playwright.
**Spec:** ../specs/2026-11-02-textlab-design.md

## Global constraints
No AI-authorship certainty or invented benchmark. No stored input text or committed secrets. No unrelated Site writes. Production requires a token and explicit allowed hosts. Text limit 12,000 characters, rewrite limit 8,000 characters.

## Review focus
Short text must abstain; unsupported languages must not acquire spurious certainty; inserted HTML must render as text; model output losing protected facts must be rejected; stale async results must not overwrite a newer input.

## Tasks
- [ ] Analyzer: failing node tests, explainable features and sentence evidence, benchmark metrics and JSONL runner; run node suite.
- [ ] Backend: failing pytest suite, schema validation, provider adapters, fact-token preservation, security/rate limits; run entire pytest suite.
- [ ] UI: React editor, analysis, rewriting, diff, settings/status, accessibility and responsive layout; production build and Playwright tests.
- [ ] Delivery: README, configuration, launch instructions, CI, source ZIP and static bundle; verify GitHub tree and main ref after upload. Record Sites block separately.
