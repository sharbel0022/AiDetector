# TextLab V5 Implementation Plan

> **For agentic workers:** Implement the independently owned subsystems in parallel;
> integrate and independently review the full branch before delivery.

**Goal:** Deliver a usable, honestly gated ML detector, segment workspace and
metered protected editing on the existing V4 architecture.

**Architecture:** React calls the authenticated FastAPI detector route through
AIService; descriptive style remains separate. JSON model inference and validation
gates determine which classifier outputs can be shown. Provider metadata feeds a
text-free shared usage ledger.

**Tech Stack:** React/Vite, Python/FastAPI, SQLite, scikit-learn for offline training.

**Spec:** `docs/superpowers/specs/2026-11-07-textlab-v5-design.md` and the user's
supplied TextLab V5 requirements.

## Global Constraints

- Work on `feature/textlab-v5`; no main merge or branch deletion.
- Preserve historical corpora, reports, artifacts and provider support.
- Null probabilities and AI-marked percentage unless separately validated.
- No secrets in browser, reports or Git; no input/output text in usage logs.
- Only actual model calls are evidence of model behavior.

## Review Focus

- A malicious or incomplete model manifest cannot activate probability labels.
- Astral characters and combining marks cannot shift segment boundaries.
- Out-of-order requests cannot display results for changed input.
- Concurrent principals cannot overspend or read one another's usage.
- A malformed or cancelled provider response must not erase already billed usage.
