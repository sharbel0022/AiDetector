# TextLab v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Track steps below.

**Goal:** Deliver concrete, tested v3 improvements with explicit evidence gaps and a reviewable PR.

**Architecture:** Retain React/Vite and FastAPI. Independent owners implement detector/evaluation, backend/providers, and UI; the coordinator integrates CI, performance, operations and evidence.

**Tech Stack:** React 19, Vite 7, Node 22, Python 3.11+, FastAPI, HTTPX, pytest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-02-textlab-v3-design.md`; supplied v3 brief.

## Global Constraints
- Branch `codex/textlab-v3`, based on latest origin/main; push and open PR, never merge or delete branches.
- No fabricated precision, model quality, scores or production status; no secrets or text logs.
- Keep local analysis local, preserve existing compatible API fields.
- Test behavioral changes before implementation; regressions must fail before fixes.

## Review Focus
- AI-edited texts must not silently become binary AI ground truth.
- Unrelated app state, stale responses and settings must not overwrite the original.
- Non-ASCII protected values and names/date words must survive provider round-trips.
- Multiple server processes must share per-user limits and concurrency atomically.
- Failed CI commands must fail the workflow; CI must never write generated code to main.
