# TextLab V4 Implementation Plan

> **For agentic workers:** Use test-first implementation and a fresh final review.

**Goal:** Integrate V3, provide a maintainable central AI service, verify V4 and
release safely to a single `main` branch when all release gates are satisfied.

**Architecture:** Retain React local style analysis; route backend AI operations
through `AIService`, separated providers and preservation validation. Keep ML
experiments outside runtime inference and preserve their provenance.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, HTTPX, React, Vite, Node, SQLite.

**Spec:** `docs/superpowers/specs/2026-11-07-textlab-v4-design.md`, derived from the
user's supplied AI DETECTOR FINAL V4 request.

## Global constraints

- Never commit `.env`, credentials or submitted user text.
- No paid requests with incomplete configuration or unauthenticated remote access.
- Preserve existing histories, experiments and offline false-positive examples.
- `semantic_equivalence_verified` is always false for the implemented checks.
- Do not treat historical evaluation data as a fresh independent holdout.
- Only delete extra branch refs after verified integration, preserving `main`.

## Review focus

- Model access failure and rate limiting must not expose upstream secrets or text.
- Non-BMP Unicode and combining marks must not break ranges or source comparisons.
- Unchanged output must be explained without falsely claiming improved quality.
- Several workers/users must share reservations without bypassing quotas.
- Environment aliases and deployed containers must use the same AI service.
